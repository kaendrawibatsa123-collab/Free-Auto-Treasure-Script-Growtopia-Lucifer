## Features
1. Auto Digging
    - Automatically digs to search for hidden treasures.
2. Auto World Switching
    - Automatically moves to the next world when all target items in the current world have been break.
3. Auto Reward Storage
    - Automatically stores collected rewards in the designated storage world.
4. Auto Reconnection
    - Automatically attempts to reconnect when the bot gets disconnected.
5. Dynamic Delay
    - Adjusts delays based on the bot's ping to avoid bot detection.
## Configuration
1. WorldsSetting
- Add your treasure worlds to `worldTreasure`.
- Set `storageWorld` to your designated storage world.
- Make sure to configure the correct door ID for entering the storage world.
2. Dynamic Delay
- Set `dynamicDelay = true` to enable randomized delays.
- Set `dynamicDelay = false` to disable randomized delays and use fixed delays.
3. Other Settings
- Set `onlyBreakTreasure = true` to break only hidden treasure items.
- Set `onlyBreakTreasure = false` to allow the bot to break other items.
